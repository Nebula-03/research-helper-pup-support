Privacy Policy — Research Helper Pup

**Last updated: October 14, 2026**

Research Helper Pup is a Chrome extension that helps you review search results and save selected passages as research notes. This policy explains what the extension accesses, why it accesses it, and where it is stored.

## Information the extension processes

- **Search results:** On supported search-results pages, the extension reads the submitted search query and visible result titles and snippets. It uses this information in the page to assess how relevant results are to the search. It does not read text as you type into Chrome’s address bar.
- **Hovered links:** When you hover over a link, the extension checks that link’s destination URL using rules and a blocklist bundled with the extension. The URL is processed locally for that check.
- **Research notes:** When you save a selected passage, the extension saves the passage, the page title, the page URL, and the save time.

## Storage and sharing

Search queries, result text, and hovered link URLs are processed locally for the features described above. The extension does not send them to a server. Link-check results may be kept temporarily in memory while the extension is running; they are not saved as browsing history.

Saved notes are stored in Chrome’s local extension storage on your device. If you choose **Connect a local .txt file**, the extension can also write your notes to that file. The file is one you select, and its access handle is kept locally so the extension can write to it again. You can remove notes in the extension and disconnect the file from Notes.

The extension does not use an account, analytics, advertising, or a remote data service. It does not sell or share your information with third parties.

## Chrome Web Store Limited Use statement

Research Helper Pup uses information accessed through its permissions only to provide its disclosed features: reviewing search results, checking hovered links, and saving passages that you choose to keep as notes. The extension does not use or transfer this information for advertising or unrelated purposes, and the developer does not allow people to read it, except where required by law or for security purposes.

## Your choices

- Save a passage only when you use the Notes save action.
- Delete a saved note using its delete control.
- Choose whether to connect a local `.txt` file, and disconnect it in Notes.
- Remove the extension to remove its Chrome-local notes. A `.txt` file you selected is a separate file on your device and is not deleted when you uninstall the extension.

## Permissions

- **Storage:** Used to keep your saved notes in Chrome’s local extension storage.
- **Access to web pages:** Used to read supported search-result content, check links you hover over, display the pup, and save the current page details with a note. The extension does not send page content or URLs to a remote service.
- **Access to a selected text file:** Granted only after you choose to connect a local `.txt` file, so the extension can write your notes there.
