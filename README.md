# Research Helper Pup — Support

This repository is the public place for the Research Helper Pup Chrome extension’s privacy information and user support. The extension’s source code is maintained separately.

## Get support

Open a [GitHub Issue](https://github.com/Nebula-03/research-helper-pup-support/issues) to ask a question or report a problem. Issues are public, so please do not include passwords, private notes, personal information, or sensitive search terms or URLs.

For a useful bug report, include:

- The extension version and your Chrome version
- What you were doing when the problem happened
- What you expected and what happened instead
- Steps to reproduce the problem, if you can

Before attaching a screenshot, remove or cover any private information.
